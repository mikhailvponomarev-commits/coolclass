# CoolClass Telegram Bot

Telegram-бот семейной школы CoolClass во Внуково.

## Возможности

- информация о школе;
- программа и математический уклон;
- расписание 09:00–18:00, понедельник–пятница;
- стоимость 60 000 ₽/месяц, всё включено, включая трёхразовое питание;
- адрес и телефон;
- сбор заявок: имя родителя, возраст/класс ребёнка, телефон, интерес;
- передача заявки менеджеру в Telegram;
- SQLite-хранилище заявок;
- готовая архитектура для последующего подключения CRM.

## Важно: Telegram ID менеджера

Бот не требует заранее знать numeric chat ID. Менеджер с username `@Mikhail7890` должен один раз открыть бота и нажать `/start`. Бот сохранит его chat ID и после этого будет присылать новые заявки лично ему.

## Запуск локально

1. Установите Python 3.12+.
2. Установите зависимости: `pip install -r requirements.txt`.
3. Скопируйте `.env.example` в `.env` и заполните `BOT_TOKEN` новым токеном от @BotFather.
4. Перед запуском экспортируйте переменные окружения (или задайте их в настройках хостинга).
5. Запустите `python bot.py`.

Токен никогда не храните в GitHub. Для production используйте Secret/Environment Variables хостинга.

## Docker

Dockerfile уже готов. Для Render, Railway, Fly.io, VPS или другого Docker-хостинга:

`docker build -t coolclass-bot .`

`docker run --env-file .env coolclass-bot`

Для persistent SQLite на хостинге подключите persistent disk/volume, чтобы заявки не терялись при перезапуске контейнера.

## CRM
